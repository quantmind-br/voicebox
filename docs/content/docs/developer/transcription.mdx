## Overview

Voicebox has an STT engine registry with two engines:

- **Whisper** — local inference through MLX on Apple Silicon or PyTorch elsewhere.
- **Gemini** — remote transcription through Google's `gemini-3.5-transcribe` API model.

Transcription powers captures, the `/transcribe` endpoint, retranscription, reference-text auto-fill, and the `voicebox.transcribe` MCP tool.

## Architecture

`STTBackend` lives in `backend/backends/__init__.py`:

```python
@runtime_checkable
class STTBackend(Protocol):
    async def load_model(self, model_size: str) -> None: ...
    async def transcribe(
        self,
        audio_path: str,
        language: str | None = None,
        model_size: str | None = None,
        *,
        options: dict | None = None,
    ) -> str: ...
    def unload_model(self) -> None: ...
    def is_loaded(self) -> bool: ...
```

`STT_ENGINES` and `get_stt_backend_for_engine()` mirror the TTS registry. Each engine has one process-wide backend instance. `backend/services/transcribe.py` exposes `get_stt_model(engine)` and `unload_stt_models()`.

Implementations:

- `MLXSTTBackend` in `backends/mlx_backend.py`
- `PyTorchSTTBackend` in `backends/pytorch_backend.py`
- `GeminiSTTBackend` in `backends/gemini_stt_backend.py`

## Whisper

Five downloadable Whisper variants are registered as `ModelConfig` entries:

| Model | HuggingFace Repo | Size | Notes |
|-------|------------------|------|-------|
| Base | `openai/whisper-base` | ~300 MB | Fast, decent quality |
| Small | `openai/whisper-small` | ~500 MB | Better quality |
| Medium | `openai/whisper-medium` | ~1.5 GB | High quality |
| Large | `openai/whisper-large-v3` | ~3 GB | Best quality, slow on CPU |
| Turbo | `openai/whisper-large-v3-turbo` | ~1.5 GB | Near-Large quality, much faster |

Models load lazily and report download progress through `model_load_progress()`. Whisper receives mono PCM and Voicebox transcodes browser containers such as WebM/Opus to WAV before inference.

## Gemini

Gemini is API-backed and contributes no `ModelConfig`: there are no local weights, model downloads, or HuggingFace cache entries. Readiness is simply whether a Gemini API key is available.

Credentials resolve in this order:

1. Non-empty `GEMINI_API_KEY` environment variable
2. Key stored in SQLite `provider_settings`

Configure provider defaults under **Settings → Providers**. Backends never read the database directly; routes and services resolve an `options` dictionary and pass it to `transcribe()`.

### Modes

- **Verbatim** — faithful transcription; optionally enables speaker diarization and word timestamps.
- **Smart** — polished transcript. Smart mode replaces Voicebox's local LLM refinement pass for automatic captures.

Smart mode cannot be combined with diarization or timestamps. Provider settings persist this invariant: selecting Smart disables both options, while enabling either option selects Verbatim.

### Language and vocabulary hints

Gemini accepts BCP-47 language codes. An empty list enables automatic detection and code switching. Voicebox maps its two-letter UI codes to region-qualified values, including `en-US`, `pt-BR`, and `cmn-Hans-CN` for Chinese.

Custom vocabulary accepts up to 1,000 terms; Google recommends keeping the list near 100 terms for best results.

### Audio transport

Native MIME types are WAV, MP3, AIFF, AAC, OGG, and FLAC. Other containers are transcoded to WAV. Audio up to the inline threshold is base64-encoded in the interaction request; larger files use Gemini's resumable Files API and are polled until `ACTIVE`.

## API

`POST /transcribe` accepts multipart form data:

```text
file: <audio_file>
language: en          # optional
model: turbo          # Whisper only, optional
engine: whisper       # whisper | gemini, optional
```

The response is unchanged:

```json
{
  "text": "Hello, this is a test transcription.",
  "duration": 3.5
}
```

Capture creation also accepts `engine`, and retranscription accepts it in the JSON request body. When no engine is supplied, the server-persisted capture setting is used.

## Output formatting

Plain responses use Gemini's `output_text`. With diarization or timestamps, Voicebox groups consecutive `word_info` annotations into speaker turns:

```text
[0:01] spk_1: Hello there
[0:04] spk_2: Hi
```

If annotations are absent, rendering falls back to `output_text`.

## Error handling

| Error | Cause | Solution |
|-------|-------|----------|
| Gemini key missing | No env or stored key | Configure Settings → Providers |
| Invalid key or quota error | Google API rejection | Use the Providers **Test** button and inspect Google's message |
| Whisper model missing | Local model not downloaded | Download it from Models or retry the triggering route |
| OOM on Whisper load | Model too large for available memory | Switch to Small or Turbo |
| Wrong language | Auto-detection misfired | Supply a language hint |
